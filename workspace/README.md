# workspace/

이 디렉터리는 AI Workspace가 관리하는 **개별 프로젝트의 실제 작업 공간**을 위해
예약되어 있습니다.

Phase 0(현재) 시점에는 비어 있으며, Phase 1에서 Project 도메인 모델과 파일 기반
저장 방식이 확정되면 프로젝트별 하위 디렉터리 구조(예: `workspace/<project-id>/`)가
정의될 예정입니다. 자세한 계획은 [`docs/ROADMAP.md`](../docs/ROADMAP.md)의
Phase 1 항목과 [`.ai/TASKS.md`](../.ai/TASKS.md)를 참고하세요.
