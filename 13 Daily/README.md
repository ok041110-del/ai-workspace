# Daily Notes 사용법

이 폴더는 날짜별 작업 기록(`YYYY-MM-DD.md`)을 담는다. 새 Daily
Note는 [[Template - Daily]]를 복사해 만든다. Index 문서가 아니므로
개별 Daily Note에는 GitHub Link Rule의 "원문" 섹션을 강제하지
않는다 — 대신 "관련 문서"에서 [[Overview]]로 돌아가는 링크만
유지한다.
