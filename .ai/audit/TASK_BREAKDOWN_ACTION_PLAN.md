# AI Workspace — Action Plan Task 분해 (Task Breakdown)

**기준 문서**: `.ai/audit/ACTION_PLAN_2ND_AUDIT.md`
**성격**: 이 문서는 구현이 아니다. `ACTION_PLAN_2ND_AUDIT.md`의 Action Item 7개(AI-01~AI-07)를 각각 독립적으로 실행 가능한 최소 단위 Task로 분해하고, Task 간 의존성을 유지한 채 가장 작은 단위부터 실행 가능한 순서로 재배열한 것이다. 새 Finding, 새 Action Item, 코드/설정 변경은 포함하지 않는다.

**Task 크기 표기**: XS(수 분~15분, 파일 1곳 텍스트/설정 변경 수준) / S(수십 분, 파일 1~2개 또는 검증 포함) / M(별도 설계 판단이 필요한 단위, ACTION_PLAN의 Medium Action Item에 대응).

## 8. 전체 실행 순서 (Topological Order, 최소 단위 우선)

Action Item 간 의존성(AI-02→AI-03-T04 권장, AI-03→AI-04, AI-06→AI-07)을 반영해 전체 Task를 실행 가능한 순서의 Wave로 재배열했다. 같은 Wave 안의 Task는 서로 의존성이 없어 병행 실행 가능하다.

**Wave 0 — 선행 조건 없음, 지금 바로 시작 가능**
`AI-01-T01`, `AI-01-T03`, `AI-02-T01`, `AI-03-T01`, `AI-04-T01`, `AI-05-T01`, `AI-06-T01`

**Wave 1 — Wave 0 일부 완료 후**
`AI-01-T02`, `AI-01-T04`, `AI-02-T02`, `AI-02-T03`, `AI-03-T02`, `AI-03-T03`, `AI-05-T02`, `AI-06-T02`

**Wave 2 — Wave 1 완료 후**
`AI-03-T04`(AI-02 완료 권장 반영), `AI-05-T03`, `AI-06-T03`(선택), `AI-07-T01`(AI-06-T02 필요)

**Wave 3 — Wave 2 완료 후**
`AI-03-T05`, `AI-07-T02`

**Wave 4 — Wave 3 완료 후**
`AI-04-T02`(AI-03-T05 필요)

**Wave 5 — Wave 4 완료 후**
`AI-04-T03`

**보류(조건부 트리거 대기, 이번 순서에 포함하지 않음)**
`AI-05-T04`(AI-05-T02 결과가 "외부 노출"일 때만), `AI-07-T03`(재확인 시점 도달 + 재성장 확인 시에만)

```
AI-01 ─ 독립 (Wave 0~1 내 완결)
AI-02 ─ 독립 (Wave 0~1 내 완결) ──┐
AI-05 ─ 독립 (Wave 0~2 내 완결)   │ (권장, 비강제)
AI-06 ─ 독립 (Wave 0~1 내 완결) ─┼──▶ AI-03-T04
   │                              │
   ▼                              ▼
AI-07-T01,T02              AI-03 (Wave 0~3 내 완결)
   │                              │
   ▼                              ▼
AI-07-T03 (보류)            AI-04-T02 ──▶ AI-04-T03
                                   ▲
                             AI-04-T01(독립, Wave 0)
```

Action Item 수준의 강한 의존은 두 개뿐이다: **AI-03 → AI-04**(CI 없이 Branch Protection에 걸 상태 검사가 없음), **AI-06 → AI-07**(정책 없이 재판단 기준을 세울 수 없음). 나머지 Action Item(AI-01, AI-02, AI-05)은 서로 완전히 독립적이며 Wave 0부터 병행 진행 가능하다.
